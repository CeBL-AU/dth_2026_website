## *What are the advantages of open source software?*

In short, open source software is “code that is publicly available for people to view, modify, and share” ([Wilkins, 2021](#ref-wilkins)). Because of this, open source software has a lot of advantages. In her article, Wilkins mentions four primary benefits: control, learning, security, and community ([2021](#ref-wilkins)).

By control, it is meant that since the code is entirely visible and you are allowed to modify it, you are able to pick and choose what parts of the code you would like to use and in what way. This is especially helpful to small developers, programmers, and researchers, that would otherwise not have the necessary capital or recourses to develop entirely new code from scratch to suit their needs. 

By extension of the code being visible, it also allows for people to study the code and learn from it. While still being highly relevant to small developers, it is also an incredibly useful tool for students and new programmers in particular. In a sense, open source software can become learning examples for newcomers and function as actual examples of how code looks and functions. 

Another benefit to this visibility, is the security that comes from it. By being publicly available, it allows for developers to more easily find and fix issues, and the individual user has the opportunity to do the same on their own device. This, in theory, should be helpful to volunteer maintainer, since issues are more likely to be found by more people. This, however, may also results in an increased workload and pressure. 

This ties into the last benefit: community. There is a large community behind open source software, which means there are a lot of resources to find. But it also means that if you have an interesting project, it is very possible to find outside help from volunteer developers. As such, any potential workload increase may be offset by and equal increase in help with development.
