## *What are the disadvantages of open source software?*

Despite the many benefits of open source software, some of the very same advantages result in certain disadvantages. Because open source software is so community focused with volunteer maintainers being common, it can run the risk of these maintainers implementing malicious code or similar. This should be quite difficult since the code is publicly available and generally code suggestions are only pushed by trustworthy individuals. However, this does always not prevent such cases from happening. 

One of the most notable cases is the XZ backdoor incident in Linux systems. In this instance, an individual was able to gain trust and commit access over two years, allowing them to gradually implement hidden malicious code. While pressure for frequent updates and the common use of volunteer maintainers is what resulted in this backdoor incident, the code being publicly available is also what allowed for the harmful code to be found before any major damage happened ([Carter, 2024](#ref-carter)).

When looking at open source software from the viewpoint of the government, municipalities, or similar, the code being publicly available can become a disadvantage, a liability. Many of these actors do not have the technical know how to write code themselves nor the ability to evaluate the code used internally. It can therefore be preferable to not get their code scrutinized by highly-technical and critical eyes, which could hurt their public image and trust ([Balter, 2014](#ref-balter)).
